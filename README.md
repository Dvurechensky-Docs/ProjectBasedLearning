# Project Based Learning

Project Based Learning is a curated programming portal for developers who learn by building real software. It collects practical tutorials, project ideas, and learning paths by programming language: Python, JavaScript, C#, C/C++, Rust, Go, Java, Kotlin, Swift, Ruby, PHP, HTML/CSS, and more.

The production site is available here:

[https://dvurechensky-docs.github.io/ProjectBasedLearning/](https://dvurechensky-docs.github.io/ProjectBasedLearning/)

## What This Repository Contains

- A GitHub Pages / Jekyll site in [`docs/`](./docs/)
- Dark responsive layout for desktop and mobile
- English-first pages with Russian mirrors under `/ru/`
- SEO metadata, canonical URLs, hreflang links, Open Graph, Twitter Card, JSON-LD, sitemap, and robots.txt
- Search across project categories
- Curated learning resources grouped by programming language
